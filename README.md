# Projeto de Açude — Calculadora

Aplicação estática em HTML, CSS e JavaScript puro, pronta para GitHub Pages. Não usa bibliotecas externas nem backend.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html` (e opcionalmente este README) para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)` e salve.
6. Aguarde a publicação e abra a URL exibida pelo GitHub Pages.

## O que calcula
- Vistas superior, frontal e lateral em SVG responsivo.
- Animação ilustrativa de enchimento.
- Dimensões do fundo e da abertura superior.
- Estimativa de dimensão da lona com sobra de ancoragem.
- Volume aproximado em m³ e litros.
- Estimativa didática de quantidade de peixes, biomassa e ração diária.

## Limitações importantes
Os cálculos são estimativas geométricas para planejamento. Não substituem avaliação do solo, projeto de escavação, orientação do fabricante da geomembrana ou orientação técnica de aquicultura. Densidade de peixes e ração dependem da espécie, qualidade da água, aeração, renovação e manejo.
